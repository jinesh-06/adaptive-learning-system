## 1. Introduction

The C programming language is a general-purpose programming language originally developed by Dennis Ritchie at Bell Labs in the early 1970s. C became closely associated with the development of the UNIX operating system and has continued to be important in operating systems, embedded systems, compilers, databases, networking software, and performance-sensitive applications.

C provides structured programming, functions, pointers, arrays, structures, unions, enumerations, and direct access to objects through memory addresses. It does not require a garbage collector or virtual machine as part of the language itself.

The current published international standard is **ISO/IEC 9899:2024 (C23)**. The standard specifies the syntax, constraints, semantics, input/output representation, and implementation limits of the C language while aiming to support portable programs across different systems.

# 4. Beginner Concepts

## 4.1 Basic Program Structure

A simple C program can contain:

1. Preprocessor directives.
2. Declarations.
3. Function definitions.
4. Statements and expressions.
5. The `main()` function.

Example:

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```

`main()` is the function from which execution of a hosted C program begins.

---

## 4.2 Comments

C supports two common comment forms:

### Single-line comment

```c
// This is a comment
```

### Multi-line comment

```c
/*
   This is a
   multi-line comment.
*/
```

---

## 4.3 Tokens and Identifiers

A C program is formed from tokens such as:

* Keywords
* Identifiers
* Constants
* String literals
* Operators
* Punctuators

Identifiers are names used for objects, functions, parameters, structures, and other program entities.

Examples:

```c
int age;
double salary;
int calculate_total(void);
```

Valid identifier examples:

```text
age
student_name
totalMarks
_count
```

An identifier cannot normally begin with a digit.

Invalid:

```text
2value
student-name
```

Keywords such as `int`, `return`, `if`, `while`, and `static` have reserved language meanings and should not be used as ordinary identifiers.

# 5. Variables and Fundamental Types

C provides several fundamental types.

## 5.1 Integer Types

Common integer types include:

```c
char
short
int
long
long long
```

They can also be signed or unsigned where permitted:

```c
signed int
unsigned int
```

The exact size of a type is implementation-dependent, subject to the minimum requirements of the C standard.

For example, `int` has a minimum width of 16 bits, but it is commonly 32 bits on modern systems.

---

## 5.2 Character Type

```c
char grade = 'A';
```

`char` is used to represent a character and occupies exactly one C byte.

The number of bits in a byte is available through:

```c
#include <limits.h>

printf("%d\n", CHAR_BIT);
```

The standard minimum for `CHAR_BIT` is 8.

---

## 5.3 Floating-Point Types

C provides:

```c
float
double
long double
```

Example:

```c
float temperature = 25.5f;
double price = 199.99;
long double value = 123.456L;
```

The precision, representation, and range of floating-point types are implementation-dependent. Many modern implementations use IEEE-754-style representations, but portable C code should use `<float.h>` to inspect the implementation rather than assuming a particular representation.

Useful macros include:

```c
FLT_MAX
DBL_MAX
FLT_DIG
DBL_DIG
```

---

## 5.4 `void`

`void` represents the absence of a value.

Example:

```c
void display_message(void)
{
    printf("Welcome\n");
}
```

A `void` function does not return a value.

# 6. Fixed-Width Integer Types

The header `<stdint.h>` provides integer types when an exact minimum width is required.

Examples:

```c
#include <stdint.h>

int8_t a;
uint8_t b;
int16_t c;
uint16_t d;
int32_t e;
uint32_t f;
int64_t g;
uint64_t h;
```

For example:

```c
int32_t student_id = 1001;
uint64_t population = 8000000000ULL;
```

These types are useful when program data must have predictable widths across implementations that provide those types.

# 7. Intermediate Concepts

## 7.1 Translation and Compilation

The C standard defines the language and its semantics; it does not require a particular compiler architecture or command sequence for transforming source code into an executable.

A typical GCC-based development workflow can be described as:

### Stage 1: Preprocessing

```bash
gcc -E program.c -o program.i
```

Common preprocessing operations include:

* Processing `#include`
* Expanding macros
* Processing conditional compilation
* Removing comments

---

### Stage 2: Compilation

```bash
gcc -S program.i -o program.s
```

The compiler analyzes the C program and generates assembly code for the target architecture.

---

### Stage 3: Assembly

```bash
gcc -c program.s -o program.o
```

The assembler converts assembly instructions into a relocatable object file.

---

### Stage 4: Linking

```bash
gcc program.o -o program
```

The linker combines object files and required libraries and resolves references between program components.

**Important:** These GCC commands describe a common toolchain workflow. They are not requirements imposed by ISO C.

# 8. Header Files and Source Files

## 8.1 Source File

A `.c` file normally contains function definitions and program logic.

Example:

```text
main.c
```

## 8.2 Header File

A `.h` file commonly contains declarations, macros, typedefs, and shared interface information.

Example:

```text

```

A simple project may contain:

```text
project/
```

This structure helps divide a program into reusable modules.

# 9. `main()` Function

A common hosted C program uses:

```c
int main(void)
{
    return 0;
}
```

or:

```c
int main(int argc, char *argv[])
{
    return 0;
}
```

`argc` represents the number of command-line arguments.

`argv` provides access to the argument strings.

Example:

```c
#include <stdio.h>

int main(int argc, char *argv[])
{
    printf("Argument count: %d\n", argc);
    return 0;
}
```

Returning zero from `main` indicates successful program termination in the usual hosted environment.

# 11. Integer Promotions

Integer types with rank lower than `int`, such as `char` and `short`, are commonly subject to integer promotions when used in expressions.

Example:

```c
char a = 10;
char b = 20;

int result = a + b;
```

The operands are promoted before the arithmetic operation.

The exact conversion rules depend on the types and values involved.

---

# 12. Usual Arithmetic Conversions

When arithmetic operands have different types, C applies conversion rules to determine a common type.

Example:

```c
int a = 10;
double b = 2.5;

double result = a + b;
```

Here, the integer value is converted to a floating-point type for the operation.

Do not memorize a simplified type ranking as if it covered every case. C conversion rules depend on integer promotions, signedness, rank, and floating-point types.

---

# 13. Explicit Type Casting

A programmer can explicitly request a conversion.

Example:

```c
int total = 10;
int count = 3;

double average = (double)total / count;
```

Without the cast:

```c
double average = total / count;
```

the division is performed using integer operands before the result is assigned to `double`.

With the cast:

```c
(double)total
```

the division is performed using floating-point arithmetic.

# 14. Implementation-Defined, Unspecified, and Undefined Behavior

Understanding these concepts is important for portable C programming.

## 14.1 Implementation-Defined Behavior

The implementation chooses a behavior and documents the choice.

Examples can include certain properties of the target implementation, such as the representation of some types.

Use standard facilities such as:

```c
#include <limits.h>
#include <float.h>
```

to inspect implementation limits.

---

## 14.2 Unspecified Behavior

The standard permits more than one possible behavior and does not require the implementation to document which choice it makes.

Portable programs should not depend on a particular unspecified choice.

---

## 14.3 Undefined Behavior

The C standard imposes no requirements when a program performs an operation classified as undefined behavior.

Examples include:

```c
int x = 10;
int y = 0;

int result = x / y;
```

and signed integer overflow such as attempting to exceed the representable range of a signed integer.

Undefined behavior should be avoided because the compiler is not required to preserve an expected result.

---

# 15. Detailed Theory: C Abstract Machine

The C standard describes program execution using an abstract model rather than prescribing a specific CPU, RAM organization, compiler, or executable format.

This allows implementations to optimize programs while preserving the behavior required by the language rules.

The commonly used term **as-if rule** describes the principle that an implementation can transform the program as long as the required observable behavior is preserved.

Therefore:

```c
int x = 10;
int y = 20;
int z = x + y;
```

does not require a particular machine instruction sequence.

The actual generated code depends on the compiler, target architecture, optimization settings, and implementation.

---

# 16. Memory and Data-Type Model

C does not require all implementations to use the same physical memory layout or type sizes.

Typical modern systems may use:

```text
char        -> 1 byte
short       -> commonly 2 bytes
int         -> commonly 4 bytes
long        -> commonly 4 or 8 bytes
long long   -> commonly 8 bytes
float       -> commonly 4 bytes
double      -> commonly 8 bytes
```

However, portable programs should not assume these sizes.

Use:

```c
sizeof(type)
```

to determine the size on the current implementation.

Example:

```c
#include <stdio.h>

int main(void)
{
    printf("char      : %zu bytes\n", sizeof(char));
    printf("short     : %zu bytes\n", sizeof(short));
    printf("int       : %zu bytes\n", sizeof(int));
    printf("long      : %zu bytes\n", sizeof(long));
    printf("long long : %zu bytes\n", sizeof(long long));
    printf("float     : %zu bytes\n", sizeof(float));
    printf("double    : %zu bytes\n", sizeof(double));

    return 0;
}
```

# 17. Platform Limits

Use `<limits.h>` for integer and character limits.

Example:

```c
#include <stdio.h>
#include <limits.h>

int main(void)
{
    printf("CHAR_BIT = %d\n", CHAR_BIT);
    printf("INT_MIN  = %d\n", INT_MIN);
    printf("INT_MAX  = %d\n", INT_MAX);
    printf("UINT_MAX = %u\n", UINT_MAX);

    return 0;
}
```

Use `<float.h>` for floating-point characteristics.

```c
#include <stdio.h>
#include <float.h>

int main(void)
{
    printf("FLT_MAX = %e\n", FLT_MAX);
    printf("DBL_MAX = %e\n", DBL_MAX);
    printf("FLT_DIG = %d\n", FLT_DIG);
    printf("DBL_DIG = %d\n", DBL_DIG);

    return 0;
}
```

# 18. Formatted Input and Output

## 18.1 `printf()`

Common conversions include:

```text
%d   signed decimal integer
%u   unsigned decimal integer
%c   character
%s   string
%f   floating-point output
%x   hexadecimal
%X   uppercase hexadecimal
%p   pointer value
%zu  size_t value
```

Example:

```c
int age = 20;
double mark = 87.5;

printf("Age = %d\n", age);
printf("Mark = %.2f\n", mark);
```

---

## 18.2 `scanf()`

For `scanf`, the conversion specification must correspond to the type of the receiving object.

Example:

```c
int age;
double mark;

scanf("%d %lf", &age, &mark);
```

For `scanf`, `%lf` is used when the destination is a `double *`.

For strings, an input width should be supplied when using `%s` to prevent writing beyond the destination array.

Example:

```c
char name[20];

scanf("%19s", name);
```

The return value of `scanf` reports how many input fields were successfully assigned, or `EOF` for an input failure before an assignment.

---

# 19. Width and Precision

Example:

```c
printf("%10.2f\n", 25.678);
```

Output:

```text
     25.68
```

Here:

* `10` = minimum field width
* `.2` = two digits after the decimal point

Left alignment:

```c
printf("%-10d\n", 25);
```

# 20. Basic Example

### Problem

Read an integer and a floating-point value and display them with their memory sizes.

```c
#include <stdio.h>

int main(void)
{
    int age = 0;
    double gpa = 0.0;

    printf("Enter age and GPA: ");

    if (scanf("%d %lf", &age, &gpa) == 2)
    {
        printf("Record Captured:\n");
        printf("Age: %-5d | Size: %zu bytes\n",
               age, sizeof age);
        printf("GPA: %-5.2f | Size: %zu bytes\n",
               gpa, sizeof gpa);
    }
    else
    {
        printf("Invalid input format.\n");
    }

    return 0;
}
```

### Sample Input

```text
20 8.75
```

### Sample Output

```text
Record Captured:
Age: 20    | Size: 4 bytes
GPA: 8.75  | Size: 8 bytes
```

The exact sizes are implementation-dependent.

# 21. Safer Line-Based Input

For beginner programs requiring more controlled input, `fgets()` can read a complete line into a bounded character array.

The line can then be parsed using `sscanf()`.

Example:

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char input[100];
    int user_id;
    double balance;

    printf("Enter User ID and Balance: ");

    if (fgets(input, sizeof input, stdin) != NULL)
    {
        input[strcspn(input, "\n")] = '\0';

        if (sscanf(input, "%d %lf", &user_id, &balance) == 2)
        {
            printf("User ID: %d\n", user_id);
            printf("Balance: %.2f\n", balance);
        }
        else
        {
            printf("Invalid input.\n");
        }
    }

    return 0;
}
```

This approach gives the program a bounded input buffer and separates line reading from conversion.

# 22. Type Inspection Example

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    int32_t number = -200000;
    uint64_t large_number = 18446744073709551615ULL;

    printf("int32_t: %d\n", number);
    printf("uint64_t: %llu\n",
           (unsigned long long)large_number);

    return 0;
}
```

For portable formatted input/output of fixed-width integer types, `<inttypes.h>` provides appropriate format macros such as `PRId32` and `PRIu64`.

# 23. Common Beginner Mistakes

## Mistake 1: Using an uninitialized variable

Incorrect:

```c
int x;
printf("%d\n", x);
```

Correct:

```c
int x = 0;
printf("%d\n", x);
```

---

## Mistake 2: Wrong `scanf()` argument

Incorrect:

```c
int age;
scanf("%d", age);
```

Correct:

```c
scanf("%d", &age);
```

---

## Mistake 3: Integer division

```c
int a = 5;
int b = 2;

printf("%f\n", (double)a / b);
```

The cast ensures floating-point division.

---

## Mistake 4: Buffer overflow with `%s`

Avoid:

```c
char name[10];
scanf("%s", name);
```

Prefer:

```c
scanf("%9s", name);
```

or use bounded line input with `fgets()`.

# 26. Portable Programming Practices

Good C programming practices include:

* Initialize variables before use.
* Check return values from input and library functions.
* Use the correct format specifier for each type.
* Use `sizeof` rather than assuming type sizes.
* Use `<stdint.h>` when fixed-width integers are appropriate.
* Use `<limits.h>` and `<float.h>` to inspect implementation limits.
* Avoid undefined behavior.
* Avoid writing beyond array boundaries.
* Compile with useful warnings.
* Keep functions small and focused.
* Use meaningful variable names.
* Separate reusable code into source and header files.
