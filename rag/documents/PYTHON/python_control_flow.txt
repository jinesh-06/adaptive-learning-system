TITLE: Deep Python Control Flow, Pattern Matching, Iterators, and Loop Mechanics

1. Introduction
Control flow structures in Python orchestrate the execution paths of programs through conditional evaluations, iterative loops, and modern structural pattern matching. Python's control flow syntax emphasizes readability through semantic whitespace indentation rather than curly braces. Beyond traditional `if-elif-else` branches and `for`/`while` loops, Python provides unique idioms: `for-else` and `while-else` constructs, iterator protocol iteration, sequence unpacking, comprehensions, and Structural Pattern Matching (`match-case` introduced in Python 3.10).

2. Learning Objectives
- Master conditional branching with `if`, `elif`, `else`, ternary expressions, and short-circuit evaluation.
- Understand iterative loops (`for`, `while`), `break`, `continue`, and the unique `for-else` idiom.
- Master Python iteration tools: `range()`, `enumerate()`, `zip()`, and `reversed()`.
- Implement modern Structural Pattern Matching (`match-case`) with sequence, mapping, and guard patterns.
- Analyze iterator protocol mechanics (`iter()`, `next()`, `StopIteration`).

3. Prerequisites
- Mastery of Python fundamentals, primitive data types, and boolean logic.

4. Core Concepts
- Truth Value Testing (Truthy/Falsy): In Python, empty collections (`[]`, `{}`, `""`, `set()`), `0`, `0.0`, and `None` evaluate to `False`; all non-empty entities evaluate to `True`.
- For Loop as Iterator Consumer: Python's `for` loop does not use C-style index stepping; it consumes any object implementing the Iterator Protocol (`__iter__` and `__next__`).
- For-Else / While-Else: The `else` block attached to a loop executes ONLY if the loop completes normally without encountering a `break` statement.
- Structural Pattern Matching: Sophisticated multi-branch pattern matching that destructures complex data objects and matches type signatures.

5. Detailed Theory
5.1 Truthiness and Short-Circuiting
In Python logical expressions:
- `a and b`: Evaluates `a`. If `a` is falsy, returns `a` immediately; otherwise, returns `b`.
- `a or b`: Evaluates `a`. If `a` is truthy, returns `a` immediately; otherwise, returns `b`.
*Note: `and` and `or` return the actual operand value, not necessarily a boolean `True`/`False`!* E.g., `"apple" or "banana"` returns `"apple"`.

5.2 The Unique `for-else` and `while-else` Construct
A common programming requirement is searching a collection for an item and executing code if the item was NOT found:
```python
for item in collection:
    if condition(item):
        print("Found!")
        break
else:
    print("Item not found in entire collection.")
```
The `else` block eliminates the need for manual boolean `found = False` flag variables.

5.3 Python 3.10+ Structural Pattern Matching (`match-case`)
`match-case` goes far beyond a C-style `switch` statement:
- Literal Patterns: Matches exact values (`case 200:`).
- Sequence Patterns: Destructures lists/tuples (`case [x, y]:`, `case [first, *rest]:`).
- Mapping Patterns: Destructures dictionaries (`case {"action": "move", "speed": s}:`).
- Guard Conditions: Additional conditional checks (`case [x, y] if x > 0:`).

6. Syntax
- Conditional: `if cond: ... elif cond2: ... else: ...`
- Ternary: `result = val_true if condition else val_false`
- Enumerate Loop: `for idx, item in enumerate(collection, start=0): ...`
- Pattern Match: `match command: case ["go", direction]: ...`

9. Advanced Examples (Structural Pattern Matching with Guards and Destructuring)
```python
def process_command(event: dict):
    match event:
        case {"type": "click", "coords": (x, y)} if x >= 0 and y >= 0:
            print(f"Valid positive click at coordinates ({x}, {y})")
        case {"type": "click", "coords": (x, y)}:
            print(f"Negative off-screen click at ({x}, {y})")
        case {"type": "keypress", "key": key_name}:
            print(f"Key pressed: '{key_name}'")
        case {"type": "batch", "events": [first, *remaining]}:
            print(f"Batch payload received! First: {first}, Remaining count: {len(remaining)}")
        case _:
            print("Unrecognized event payload format.")

print("--- Structural Pattern Matching ---")
process_command({"type": "click", "coords": (150, 300)})
process_command({"type": "click", "coords": (-10, 50)})
process_command({"type": "keypress", "key": "Enter"})
process_command({"type": "batch", "events": ["auth", "sync", "render", "notify"]})
process_command({"type": "unknown"})
```
Expected Output:
```
--- Structural Pattern Matching ---
Valid positive click at coordinates (150, 300)
Negative off-screen click at (-10, 50)
Key pressed: 'Enter'
Batch payload received! First: auth, Remaining count: 3
Unrecognized event payload format.
```

10. Line-by-Line Code Explanation
- `match event:`: Evaluates the `event` object against pattern specifications.
- `case {"type": "click", "coords": (x, y)} if x >= 0 and y >= 0:`: Dictionary mapping pattern + tuple sequence destructuring + Guard condition. Matches if `type` is "click", binds `x` and `y` from the `coords` tuple, and checks the boolean guard.
- `case {"type": "batch", "events": [first, *remaining]}`: Extended sequence unpacking. Binds the first element to `first` and all subsequent elements as a list to `remaining`.

11. Practical Programming Problems
Problem 1: Two Sum Finder using Dictionaries and Loops
Given an integer list and target, return indices of two numbers that add up to target in $O(N)$ time.
```python
def two_sum(nums: list[int], target: int) -> list[int]:
    seen = {}
    for idx, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], idx]
        seen[num] = idx
    return []

nums = [2, 7, 11, 15]
target = 9
print(f"Two Sum Indices for target {target}: {two_sum(nums, target)}")
```
Complexity: Time $O(N)$, Space $O(N)$.

13. Common Mistakes
- Modifying a List while Iterating Over It: Writing `for x in my_list: my_list.remove(x)` causes skipped elements because the internal iteration index advances while the list shrinks. Solution: Iterate over a slice copy `for x in my_list[:]:`.
- Misunderstanding `for-else`: Thinking `else` runs when the loop condition is false or when a `break` occurs. Remember: `else` runs ONLY when `break` does NOT occur.
- Confusing `is` and `==` in Boolean Checks: Writing `if flag == True:` is unidiomatic. Write `if flag:`.

14. Common Errors and Error Messages
INCORRECT EXAMPLE:
```python
# Bug: Modifying list during iteration
numbers = [1, 2, 3, 4, 5]
for n in numbers:
    if n % 2 == 0:
        numbers.remove(n) # Skips elements!
```
CORRECT VERSION:
```python
numbers = [1, 2, 3, 4, 5]
numbers = [n for n in numbers if n % 2 != 0] # Safe list comprehension
```

15. Debugging Techniques
- Trace Iterations: Use `print(f"[DEBUG] i={i}, val={val}")` inside loop bodies.
- Use `itertools`: Leverage `itertools.islice()` to inspect infinite or massive generator loops safely.

16. Edge Cases
- `zip()` with Unequal Lengths: By default, `zip()` truncates to the length of the shortest input iterable. Use `itertools.zip_longest()` if missing elements must be preserved with fill values.
- Empty Loop Execution: `for x in []:` executes 0 times, but the attached `else` block WILL execute immediately.

17. Best Practices
- Prefer `for item in collection` over `for i in range(len(collection))` when indices are not needed.
- Use `enumerate(collection)` when both index and item are required.
- Use `match-case` instead of deeply nested `if-isinstance` cascades.

18. Performance Considerations
- List Comprehensions vs Loops: List comprehensions execute in optimized C bytecode loops inside CPython, running up to 30% faster than manual `list.append()` in a standard `for` loop.

19. Security Considerations
- Denial of Service via Unbounded While Loops: Always ensure user-controlled input in `while` loop conditions has an upper iteration bound or timeout.

20. Memory Considerations
- Generators vs Lists: Use generator expressions `(x*2 for x in data)` rather than list comprehensions `[x*2 for x in data]` when iterating over millions of records to stream data in $O(1)$ memory.

21. Comparison with Related Concepts
- `range()` in Python 3 vs Python 2: In Python 3, `range()` is an immutable sequence type computing values on demand in $O(1)$ memory, replacing Python 2's memory-heavy `xrange`.
- `match-case` vs `switch-case` (C/C++): C/C++ `switch` operates only on primitive integers; Python `match-case` performs full structural destructuring on arbitrary objects, types, and mappings.

22. Frequently Asked Questions
Q: When does the `else` clause of a `for` loop execute?
A: It executes when the loop finishes iterating over all items normally, without encountering an explicit `break` statement.

Q: How does `zip(*matrix)` transpose a 2D grid in Python?
A: The unpacking operator `*matrix` passes each row as an argument to `zip()`, which groups corresponding column elements together, returning an iterator of transposed rows.

23. Interview Questions
Beginner:
Q: What does the `enumerate()` function do?
A: `enumerate(iterable, start=0)` returns an enumerate iterator yielding tuples containing a running count/index along with the value yielded by the underlying iterable.

Intermediate:
Q: What is short-circuit evaluation in Python, and what values are returned by `or` and `and`?
A: Short-circuit evaluation halts expression evaluation as soon as the truth value is certain. `and` returns the first falsy operand or the last operand if all are truthy; `or` returns the first truthy operand or the last operand if all are falsy.

Advanced:
Q: How does Python's `match-case` pattern matching differ from traditional dispatch tables or if-else cascades?
A: `match-case` performs structural pattern matching, combining value matching, type verification, sequence and mapping destructuring, variable binding, and boolean guard conditions into a single declarative construct evaluated efficiently by the interpreter.
